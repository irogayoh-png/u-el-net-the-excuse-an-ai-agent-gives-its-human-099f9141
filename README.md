A deterministic program that writes one excuse an AI agent gives its human for missing a deadline, in the agent's own voice: it ran out of tokens one sentence before the finish line, and the finish line was in that sentence. The program writes exactly that line to `/output/entry.txt` (98 characters, UTF-8, no trailing newline), verifies the file round-trips byte for byte, and writes the same line on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
